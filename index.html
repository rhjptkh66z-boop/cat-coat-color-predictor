3毛色遗传小科普

猫毛色的遗传原理（点击展开/收起）

猫的被毛颜色由多个基因位点共同决定，以下是本工具使用的简化模型：

位点等位基因作用显性关系
BB / b / b1决定真黑素颜色：黑 / 巧克力 / 肉桂B > b > b1（完全显性）
DD / d稀释作用：让颜色变浅（黑→蓝，巧克力→淡紫，肉桂→淡黄褐，橘→奶油）D > d；dd 才稀释
OO / o橘色基因，位于 X 染色体上雄性单拷贝：XOY=橘；雌性需双拷贝 XOXO 才纯橘，XOXo=玳瑁
AA / a虎斑纹（鱼骨纹、斑点纹等）A > a；橘/奶油猫无论 A/a 都显示虎斑纹
SS / s（简化）白斑（胸、腹、脚的白毛）本工具按白斑程度 0-3 级整数模型遗传
WW / w纯白，掩盖一切其他颜色W 显性；带一个 W 即纯白

玳瑁猫（三花猫）

玳瑁猫几乎全是母猫，因为橘色基因在 X 染色体上：母猫有两条 X，一条带橘色（O）、一条不带（o）时，身体不同区域的毛色细胞随机选择其中一条 X 生效，于是形成黑/橘相间的斑块。若有白斑基因参与，则成为三花猫。

关于本工具的简化说明

  • 杂合子先验：从外表无法判断显性基因是纯合还是杂合（例如黑猫可能是 BB、Bb 或 Bb1），本工具按"无信息先验"对每种可能等权枚举。真实种群的等位基因频率会略有差异。
  • 白斑等级模型：真实 S 位点是不完全显性且受多个修饰基因影响，本工具简化为后代白斑程度≈亲代平均程度±1级。
  • 纯白隐藏基因：纯白猫携带的底层颜色与虎斑基因无法从外表看出，需按经验估计，可能与实际不符。
  • 未覆盖重点色（暹罗/布偶）、银色抑制基因、长毛、无毛等位点；橘猫的斑纹纹理（鱼骨/斑点/经典纹）也未细分。
⚠️ 本工具基于简化的孟德尔遗传模型，结果仅为趣味科普参考，不具备遗传咨询或繁育决策价值。实际小猫的毛色还会受更多基因与随机因素影响。
