# 猫咪毛色遗传预测器 🐾

上传父猫、母猫的照片并勾选毛色特征，预测它们后代的毛色概率分布——以「SVG 示意图 + 文字」形式直观展示。

**👉 在线体验：** https://rhjptkh66z-boop.github.io/cat-coat-color-predictor/

## 功能特性

- 📷 上传两张猫咪照片（仅本地浏览器处理，不上传服务器）
- 🎨 手动勾选毛色：性别、8 种基色（黑/蓝/巧克力/淡紫/肉桂/淡黄褐/橘/奶油）、虎斑、白斑程度、纯白（含底层色）、玳瑁/三花（仅母猫）
- 🧬 六基因位点孟德尔模型：B（黑/巧克力/肉桂）、D（稀释）、O（X 连锁橘色）、A（虎斑）、S（白斑等级）、W（纯白）
- 📊 后代毛色概率分布：公猫/母猫后代分组，每张卡片 = 参数化 SVG 示意猫 + 表型名 + 概率百分比 + 特征描述
- 📖 内置遗传科普（基因位点表、玳瑁原理）+ 免责声明

## 使用方法

1. 打开上面的在线链接（或直接双击本地 `index.html`）
2. 上传两只猫的照片（可选，不传也能用）
3. 为每只猫勾选性别、毛色、虎斑、白斑等特征
4. 点击「计算后代毛色概率」查看结果

## 技术说明

- **单文件网页**：纯 HTML + CSS + JavaScript，零依赖、无构建、完全离线可用
- 表型 → 基因型按「无信息先验」等权枚举（显性表型可能是纯合或杂合）
- X 连锁遗传：橘色基因位于 X 染色体，玳瑁（三花）几乎只见于母猫
- SVG 示意猫使用确定性伪随机（djb2 + mulberry32），同一表型每次渲染完全一致
- 照片仅在浏览器本地通过 canvas 压缩预览，不会上传到任何服务器

## 免责声明

⚠️ 本工具基于简化的孟德尔遗传模型，结果仅为趣味科普参考，**不具备遗传咨询或繁育决策价值**。实际小猫的毛色还会受更多基因与随机因素影响。
